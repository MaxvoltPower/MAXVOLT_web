## 🎯 Deploy in 4 Simple Steps

### Step 1: Push to GitHub (2 minutes)

If you have Git installed:
```bash
cd maxvolt-website
git init
git add .
git commit -m "MAXVOLT website - ready for production"
git remote add origin https://github.com/YOUR_USERNAME/maxvolt-website.git
git branch -M main
git push -u origin main
```

**No Git?** Use GitHub's web interface:
1. Create repo at https://github.com/new
2. Click "Upload files"
3. Drag & drop maxvolt-website folder
4. Commit

### Step 2: Connect to Netlify (1 minute)

1. Go to https://app.netlify.com
2. Sign up FREE with GitHub
3. Click "New site from Git"
4. Select your maxvolt-website repository
5. Click "Deploy site"

**That's it!** Netlify auto-detects everything.

→ Create free account at https://github.com (takes 1 minute)

→ Use GitHub web interface to upload files (no coding needed)

### "Website looks different"
→ Clear browser cache: Ctrl+Shift+Delete (or Cmd+Shift+Delete on Mac)

### "Links not working"
→ Make sure file paths use `/` not `\`
→ Check file names (case-sensitive)

### "WhatsApp not opening"
→ Make sure phone number format is: `917595941311` (with country code)
