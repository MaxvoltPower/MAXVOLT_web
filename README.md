A complete, professional, premium website for MAXVOLT with:

### 🎯 Core Features
- **Homepage** with hero, categories, and engagement sections
- **5 Product Category Pages** (home batteries, car, TOTO, e-bike, UPS)

2. Add/remove products
3. Update prices
4. Upload new images

### Adding Categories

2. Update text
